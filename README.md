# Rock Music

Rock Music is a premium native Android music platform built with Kotlin, Jetpack Compose, Material 3, and Media3.

> Initial repository seed. The Android foundation is developed through reviewed pull requests.

## Product principles

- Legal, provider-compliant playback and downloads only
- Native background audio through Media3
- Local music, podcasts, synchronized lyrics, Echo Find, social rooms, and playlist migration
- Privacy-first permissions and encrypted authentication storage
- Phone, tablet, foldable, and landscape support
